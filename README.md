# 🌙 Dreamcatcher – AI-Powered Dream Analysis & Visualization

Dreamcatcher is an AI-powered application that analyzes dreams based on user-provided keywords, emotions, and additional context. It combines Natural Language Processing (NLP) and Generative AI to interpret the emotional sentiment of dreams, generate personalized interpretations, and visualize dreams through AI-generated images.

## ✨ Features

- **Dream Sentiment Analysis:** Uses Hugging Face Transformers to identify the emotional sentiment behind a dream.
- **AI-Powered Dream Interpretation:** Leverages GPT-2 to generate personalized and dynamic interpretations based on dream keywords, feelings, and additional context.
- **AI Image Generation:** Uses Stable Diffusion 2 to transform dream descriptions into visually generated images.
- **Interactive User Experience:** Collects dream keywords, emotional responses, and additional details through an interactive command-line interface.
- **Automated Visualization:** Generates and saves a visual representation of the user's dream as a PNG image.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash

```

```bash
pip install transformers torch diffusers pillow
```

### 3. Run the Application

```bash
python main.py
```

On the first run, Hugging Face will automatically download the required pretrained models.

## 🚀 How It Works

Dreamcatcher follows a five-step workflow:

1. **Dream Input:** Users enter keywords describing their dream.
2. **Emotional Context:** Users provide information about how they felt during the dream and share any additional details.
3. **Sentiment Analysis:** The Hugging Face sentiment-analysis pipeline evaluates the emotional tone of the combined input.
4. **Dream Interpretation:** GPT-2 generates a personalized interpretation using the dream keywords, detected sentiment, and user-provided context.
5. **Dream Visualization:** Stable Diffusion 2 generates an animated-style visual representation of the dream and saves it locally.
